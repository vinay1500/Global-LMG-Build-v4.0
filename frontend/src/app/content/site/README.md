# Public Site Content

Edit public website copy in this folder.

- `home.ts`: homepage hero, intro, carousel, spotlight, insights teaser, expertise teaser.
- `about.ts`: About page copy, metrics, and feature cards.
- `services.ts`: public service catalog and service-detail copy.
- `legal.ts`: terms, refund/cancellation, privacy, cookie, and legal disclaimer documents.
- `careers.ts`: careers landing page, categories, and openings.
- `newsroom.ts`: newsroom page copy and news items.
- `faq.ts`: future FAQ copy.
- `common.ts`: shared navigation, footer, and public fallback copy.

Keep authenticated dashboard/API data separate. Portal content that comes from backend responses should stay in the relevant API or dashboard modules.
